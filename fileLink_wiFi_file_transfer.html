📱 About FileLink

FileLink: WiFi File Transfer is a utility app developed by Lihka, based in Nagpur, Maharashtra, India. It lets you send and receive files — photos, videos, documents, and archives — between smartphones, tablets, and computers over a shared WiFi network, without needing mobile data or an internet connection.

Core features include direct device-to-device transfer via local IP address, QR code pairing for quick connections, a browser-based file manager accessible from any device on the network, and optional PIN protection for secure sessions.

📌 Scope of this Policy This Privacy Policy explains what information FileLink accesses, how it is used, and what control you have over it. It applies to the FileLink Android application and its companion web interface used during active transfer sessions.

4

🔄 How Files Are Transferred

When you start a sharing session, FileLink creates a local web server on your device's own WiFi network and generates a unique access URL and QR code (e.g. http://192.168.1.3:8080). Other devices on the same network can connect to this address to send or receive files directly.

  • ✅ Transfers occur peer-to-peer over your local WiFi — no internet required
  • ✅ No file ever passes through an external or cloud server
  • ✅ Sharing automatically stops when you tap "Stop Sharing" or close the app
  • ✅ Each session can be protected with a PIN and has an optional auto-expiry timer
🌐 Network Scope Because transfers rely on your local network, only devices connected to the same WiFi (or those you explicitly share the connection link/QR with) can access your shared files.
5

🔐 PIN & Security Features

FileLink offers optional security layers so you decide how protected your sharing sessions are:

  • 4-Digit PIN: Set a PIN to restrict access to your shared files page
  • Session Expiry: Secure sessions automatically lock after a set period (e.g. 30 minutes) of inactivity
  • Manual Stop: You can end a sharing session instantly at any time
🔒 Local Storage Only Your PIN is stored securely and locally on your device. It is never transmitted to FileLink or any third party, and we have no way to view or recover it.

🗄️ Data Retention

  • Transferred files remain only on the sending and receiving devices — FileLink keeps no copies
  • PINs and session settings are stored locally until changed, reset, or the app is uninstalled
  • Crash and diagnostic logs are retained temporarily by our crash-reporting provider for bug-fixing purposes, then purged
